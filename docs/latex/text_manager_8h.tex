\doxysubsection{Detailed Description}
Manager per la visualizzazione del testo. 

Questo file contiene la classe {\ttfamily \doxylink{class_text_manager}{Text\+Manager}} che si occupa della gestione e visualizzazione del testo sulla finestra grafica. La classe può visualizzare una lista di stringhe e i frame per secondo (FPS) in un contesto 3D, utilizzando un\textquotesingle{}ortho camera (una proiezione ortogonale) per il rendering.
