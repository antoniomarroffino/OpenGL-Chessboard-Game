Detailed Description

Classe per la gestione della visualizzazione del testo.

La classe TextManager si occupa di visualizzare testo sulla finestra grafica, utilizzando una Camera ortogonale per la proiezione. Supporta la visualizzazione di una lista di stringhe e dei frame per secondo (FPS).

Visualizza una lista di testi sulla finestra.

Questo metodo utilizza la proiezione ortogonale per rendere il testo visibile nella finestra grafica. Ogni stringa viene visualizzata a partire dalla posizione verticale definita, incrementando la posizione verticale per ogni riga di testo.
